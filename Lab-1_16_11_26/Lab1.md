2. GitHub Instructions:
Our teacher introduced us to GitHub and explained how we will use it throughout the semester.
  (i) Every student must have a GitHub account.
  (ii) We have to upload our daily lab tasks to GitHub.
  (iii) All lab tasks should be uploaded regularly.
  (iv) GitHub will be used to store and manage our lab work.
  (v) At the end of the course, every student has to complete and submit a final project based on the topics learned in the lab.
